## Branch 4: the battery

`venv/bin/python bench/t4_battery.py --arms fp8fa2,int8 --cells residue,quality,d60,d90,soak --soak-minutes 30`, detached in one container, fp8fa2 first. d149 and the 240-min soak are left to the native battery. Started 11:25 UTC and finished 13:04 UTC.

**A first start was refused (kept).** With `--env KV_MEM=5046586572` (shipped 5583457484 minus 512 MiB), the fp8fa2 residue boot stopped at KV sizing: `To serve at least one request with the model's max seq len (131072), (4.83 GiB KV cache is needed, which is larger than the available KV cache memory (4.69 GiB). … estimated maximum model length is 125840`. That is not a spill and not an OOM. On 0.31.0, `CTX=long` needs about 4.83 GiB at `MAX_LEN` 131072, so the shipped `KV_MEM` leaves only about 0.35 GiB of slack, and 512 MiB less cannot boot either arm. The run was stopped during its quality boot and started again at the shipped `KV_MEM`. Its logs are kept in `t4-wsl2-2026-10-12-attempt1-kvmem-refused/`.
