  So about 0.7–1.0 GiB of the shipped `SPEC=dflash2 CTX=fast` working set ended up in host RAM. A6 compares verdicts, so its pass stands. Every timing after 08:24 UTC was taken in the spilled state. 3. `prepare` with `FAST_VARIANT=0 DFLASH2=0`, run on each copy. main used the image's `prepare/`. #294 bind-mounted `~/hq-wt/pr294/prepare` (`8da90dd`; `quant_schema.py` is 151 lines there, 71 on main) read-only over `/app/prepare`.
