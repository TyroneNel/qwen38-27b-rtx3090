## 6. Divergences to watch

1. **Baseline drift on 8.6 for `SPEC=mtp CTX=long`.** After adopting b4b97ec the default KV path is int8 + `pth_flash_attn` (`--attention-backend CUSTOM`) instead of fp8 + FlashInfer, if the package is installed and `DRAFT_TOKENS` is unset or 3 (`resolve_config.sh:105-107,113-120`). An A/B that sets `DRAFT_TOKENS=4`, `DYNAMIC_K`, `VISION=1`, or `--speculative-config` in `EXTRA_ARGS` silently falls out of the pth default and runs on the old backend (gates at `resolve_config.sh:90-94` and `:109-111`) [review: 90-94 are the comment that lists the gates; the code gates are `:106` (FA2_FP8KV, DRAFT_TOKENS, VISION), `:109` (DYNAMIC_K, offload tier) and `:110-112` (EXTRA_ARGS)]. EAGLE-4 drafter trials at k other than 3 would therefore compare against a different attention backend than the default arm. Pin `PTH_FA` explicitly in every experiment and read the `[effective-config]` line.
2. **Image vs checkout skew.** The brief says GPU runs use `ghcr.io/syv-ai/hyperqwen:sha-2cf50a0`. 2cf50a0 is the parent of 63f7581 and contains b4b97ec and 373a695, while our checkout at 95ac251 has neither (**measured**: both are in `origin/main..upstream/main`). If the box runs launchers from the image and docs/tests from our checkout, behaviour (PTH default on mtp, perf_counter timing) and docs disagree. Whether launchers are baked in or bind-mounted is unknown to me (open question 1). Fast-forwarding removes the skew.
3. **Timing on WSL2.** Before 373a695, `bench/*.py` TTFT/decode figures on Docker Desktop/WSL2 can read short, even negative, by up to ~2.3 s per ~28 s clock step (upstream-reported cause; upstream's test reproduces it). Treat short-TTFT numbers taken without it with suspicion, including any DeepInfer 3090 figure produced by `time.time()` tools.
4. **Blank LABD corpus risk.** `bench/labd_bench.py:42-43` and `bench/labd_accept.py:180-181` on `upstream/main` still glob `~/qwen-serving`. On a differently named checkout they benchmark a newline-only prompt. PR 353 fixes it. A frozen corpus on disk masks the problem.
5. **Concrete merge conflicts** (all from `git merge-tree`, **measured**): `bench/README.md` is the hot file: PR 354 x 358; `research/deepinfer` x 355 and 357; `ctx-profile-sweep` x 354 and 358; each a one-row table conflict. `bench/quality_battery.py` is edited by PR 359 and by `research/deepinfer` but auto-merges. `single-user/start_qwen.sh` and `single-user/README.md` conflict for every stale fork branch (`dynamic-k-results`, `issue-60174-*`, `launcher-seat-print`, `cline/gf59cdmh`, `prefix-cache-*`): cherry-pick docs/results only. `launcher-tp-equals` conflicts in `launcher_common.sh`. `origin/master` conflicts in many files (`.env.example`, `bench/api_smoke.py`, `bench/quality_battery.py`, ...).
6. **Launcher refactor churn.** PR 355 rewrites Vision handling in three launchers and `launcher_common.sh` (+22). Local launcher edits for an EAGLE-4 integration should rebase onto it early or after it, not between.
